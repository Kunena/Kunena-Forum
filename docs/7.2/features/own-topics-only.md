# Users see only their own topics (helpdesk)

> **Label:** `feature` · **Since:** Kunena 7.2 · **For:** Administrators · **Issue:** [#6758](https://github.com/Kunena/Kunena-Forum/issues/6758)

A category can work as a helpdesk: a user only sees the topics he started.

The setting **Users see only their own topics** in the category form turns a category into a helpdesk.

![The settings of a category](../images/admin-category-settings.png)

- Moderators of the category and administrators see all topics.
- Other users get no access to the topic and its messages. The topics are left out of the lists of topics, the search, the counts and the
  last post of the category.
- The setting is kept in the parameters of the category (no database change).
