# Order of the attachments of a message

> **Label:** `feature` · **Since:** Kunena 7.2 · **For:** Administrators

Choose how the attachments of a message are sorted.

Two template options set the order of the attachments of a message: the property and the direction.

| Option | Choices | Default |
| --- | --- | --- |
| Order of the attachments | ID (order of uploading), Date (last change of the file), Name, Size, Type (images, documents, ...) | ID |
| Direction of the attachments order | Ascending, Descending | Ascending |

Both are in Kunena, Templates, Aurelia, tab *Features*. The default is the behaviour of before: the order of uploading.
