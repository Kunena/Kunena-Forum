# Category alias with the id

> **Label:** `feature` · **Since:** Kunena 7.2 · **For:** Administrators · **Issue:** [#5802](https://github.com/Kunena/Kunena-Forum/issues/5802)

An option to start the automatic alias of a category with its id, for example 12-general.

The alias of a category is the part of the address of the forum pages. With this option the alias made from the name starts with the id of
the category.

## How it looks

![Category id in the alias](../images/option-categoryAliasId.png)

## How it works

- It is used when the alias is made from the name: for a new category, or for a category whose alias is emptied.
- An alias you type yourself is never changed, and the aliases of the existing categories stay as they are.

| Option | Where | Default |
| --- | --- | --- |
| Category id in the alias | Kunena configuration, tab *SEO Settings* | No |
