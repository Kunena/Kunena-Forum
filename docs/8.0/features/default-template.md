# Agora is the default template of a new install

> **Label:** `feature` · **Since:** Kunena 8.0 · **For:** Administrators

A new install of Kunena 8.0 shows the forum with the **Agora** template. Aurelia, the default template of Kunena 6 and 7, is still
installed and can be chosen at any time.

## Upgrade

A forum which is upgraded keeps its template: a forum with Aurelia stays on Aurelia, also when its template was never saved in the
configuration (it had the former default). To change it, open **Components → Kunena Forum → Templates** and make Agora (or
another template) the default.
