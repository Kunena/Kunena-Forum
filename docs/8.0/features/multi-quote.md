# Multi-quote

> **Label:** `feature` · **Since:** Kunena 8.0 · **For:** Users

Quote several messages of a topic in one reply.

## How to use it

Each message which can be quoted has a **Multi-quote** button next to *Quote*. A click adds the message to the quotes of the reply
(the button is shown pressed); a second click takes it out. While messages are chosen, a bar at the bottom of the screen shows:

- **Reply with N quotes**: the reply form opens with a `[quote]` block of each chosen message, the oldest first;
- **Clear the quotes**: the choice is emptied.

The choice is kept per topic while the browser tab is open, also on the other pages of the topic. It is emptied when the reply form
is opened with it. At most 10 messages are quoted in one reply.

The quotes are the same as the ones of the *Quote* button: the confidential and private parts of a message are left out. Only the
messages of the topic which the user may read are quoted.

The buttons and the bar need JavaScript; without it the *Quote* button of each message works as before.
