# A link to a category: forum#123

> **Label:** `feature` · **Since:** Kunena 7.2 · **For:** Users · **Issue:** [#6857](https://github.com/Kunena/Kunena-Forum/issues/6857)

An address like example.com/forum#123 goes to the category, and opens the section when it is collapsed.

Every category row and section header of the index has an id. A link like `example.com/forum#123` (or `#category123`, `#section123`)
goes to the category and opens its section when the section is collapsed.

![The forum index](../images/forum-index.png)

*Every row of the index can be linked: the category General Discussion is `#category3`.*

The change also tidies up the styling of the lists of topics: the spacer row between sticky and normal topics, the action row at the bottom
of the lists, the status and destination dropdowns (they only show for their action), the button for a new section (only on the
index), the jump list and the tags under the title of a topic.
