# The subscribers of a category in the backend

> **Label:** `feature` · **Since:** Kunena 8.0 · **For:** Administrators · **Issue:** [#6549](https://github.com/Kunena/Kunena-Forum/issues/6549)

An administrator can see which users are subscribed to a category.

The tab **Subscribers** is in the category form in the backend, after the Moderators tab. Its title shows the number of
subscribers, for example "Subscribers (3)".

- The tab lists the users subscribed to the category: their username, real name and id, ordered by username.
- Banned users who are subscribed are in the list too.
- A category without subscribers shows "Nobody is subscribed to this category." instead of the list.
- The tab is shown for an existing category only, not for a new category and not for a section.
- The list only shows: it can not add, remove or change a subscription.
- The subscriptions to the topics of the category are not in the list, nor the users of a subscription to a parent category.
- No e-mail is sent to the administrators when a user subscribes or unsubscribes.
