# Report the author of a message to StopForumSpam

> **Label:** `feature` · **Since:** Kunena 7.2 · **For:** Moderators, administrators

A button in the Moderate menu reports a spammer to StopForumSpam.

The Moderate menu of a message has a last entry, **Report to StopForumSpam**, for administrators and moderators. It is shown when the
StopForumSpam API key is filled in. After a confirmation Kunena sends the user name, the e-mail address and the IP address of the author, and
the message as evidence. A report which is refused no longer ends in an error: the moderator gets a message.
