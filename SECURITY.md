# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 8.0.x   |  |
| 7.1.x   | :white_check_mark: |
| 6.4.x   | :white_check_mark: |
| < 6.3   | :x:                |

## Reporting a Vulnerability

Please send an email to security@kunena.org with an example or a proof of concept.

We will answer within a week, depending on the availability of the volunteers.
After the confirmation we will work on the fix asap.


## Bug Bounty

Sorry, we have no bug bounty rewards for the reports. All our donations are going to the server costs. But your name will be added to the version doc.
