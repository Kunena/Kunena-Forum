# The author reads his own topic while it waits for approval

> **Label:** `feature` · **Since:** Kunena 7.2 · **For:** Users · **Issue:** [#5381](https://github.com/Kunena/Kunena-Forum/issues/5381)

A user who starts a topic in a category with review can open it before a moderator approves it.

After posting, the author lands on his topic with the notice that it waits for review, instead of the category. The page shows
his message styled as unapproved, without the moderation buttons. He can edit or delete it as the options of the forum allow
for any message (*User Edits*, *User Edit Time*, *User Can Delete Own Post*). An edit does not approve the topic: it stays unapproved,
and after the edit the author is back on his topic.

Nobody can reply to the topic until a moderator approves it, the author included. The other users and the guests cannot open
it, and the moderators see it as before.

Not covered: the replies of a user which wait for approval in a published topic, and the unapproved topics in the lists
(category, recent topics, the topics of the user, search, feeds). A topic posted anonymously has no author to show it to.
